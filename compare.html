Pronunciation comparison demo

To demonstrate the real-world impact of the Reo Rite correction framework on Te Reo Māori pronunciation in TTS systems. A selection of common and complex Māori words were tested using AWS Polly. Two versions were recorded one without Reo Rite correction which shows default system pronunciation and another with Reo Rite correction which shows segmentation, IPA tuning, and pronunciation adjustment.

Each example below allows direct side-by-side listening to highlight the improvements achieved with the Reo Rite system.
